Verified repository

A generic remote Pi terminal breaks the chain.

  • No shared filesystem: local paths and sentinels are not remote facts.
  • Host absolute paths and extension digests cannot identify remote executables.
  • A process in Vercel cannot call the host’s local Herdr socket.

Conclusion: official plugin + custom Pi command is a terminal demo, not result/question/resume/nesting/ownership parity.

  • Dedicated Firecracker microVM: private kernel, filesystem, processes and network namespace.
  • Named persistent Sandbox; each session is one VM boot. Stop preserves filesystem, not processes.
  • Supported interactive CLI path with raw stdin/stdout, resize, exit frame and timeout extension.
  • Command and file APIs, names, stop/resume and snapshots.
  • Official Herdr precedent: one local pane to one persistent named Sandbox.

Fail the PoC, do not weaken the contract

Six reasons to stop and choose another path.

Hard stops / 09
Reliable interaction/recovery requires copying an undocumented WebSocket protocol without a stable Vercel contract.
Disconnect leaves an unidentifiable Pi writer that cannot be safely reattached or killed.
The runner cannot distinguish VM interruption from Pi completion.
Remote loadout or session identity cannot be proven before resume.
Required authentication needs broad, long-lived host secrets and brokering is unworkable.
Required profiles depend on host sockets/paths—or nesting cannot be deferred.
Local Docker

First choice if the goal is only “keep tools off the host”; shared files preserve current watcher assumptions.

SSH host + Herdr

Lower-complexity persistent remote path when hardened development VMs already exist.

Vercel

Choose only when managed microVM isolation, burst, disposability and egress controls justify protocol work and metering.

Before funding the build

Ten owner decisions define the PoC envelope.

Decisions / 10
Eligible profiles

Name them. Nested profiles are rejected for MVP; decide Claude, GUI/browser and host-integrated exclusions.

Spawn policy

Explicit target, per-profile default or automatic? Explicit opt-in recommended.

Session authority

Accept remote-canonical JSONL with a local mirror/locator, or require continuous local mirroring?

Writeback

Reviewed upload + explicit Git patch recommended; remote Git credentials or another model?

Provider authentication

Interactive login, short-lived injection or brokering—and may login persist in snapshots?

Network policy

Exact allowed domains/tools; default-deny; temporary preparation egress?

Interruption policy

Stop on inactivity + explicit recover, or automatic recover? Set timeout and max task length.

Retention + cleanup

Snapshot count/TTL, transcript retention, deletion confirmation and named orphan owner.

Plan + residency + budget

Vercel plan, region/data residency, concurrency and daily spend cap.

Fallback

If recovery is unreliable, choose Docker or SSH rather than weakening completion/kill guarantees.

Decision principle The PoC is not approved by a successful terminal demo; it is approved by explicit scope, ownership and passed semantic gates.
